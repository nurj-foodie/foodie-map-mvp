# 📝 SESSION WRAP-UP PROMPT TEMPLATE

**Purpose:** Use this prompt at the end of each session to get a comprehensive summary

---

## 🎯 STANDARD WRAP-UP PROMPT

Copy and paste this prompt at the end of your session:

```
Session wrap-up: Please create a comprehensive summary of this session including:

1. **What We Accomplished:**
   - Major tasks completed
   - Files created/updated
   - Decisions made
   - Features implemented

2. **Key Decisions Made:**
   - Important choices and their rationale
   - Design decisions
   - System configurations

3. **Files Created/Modified:**
   - List all files changed
   - Brief description of changes
   - New files created

4. **Problems Encountered:**
   - Issues faced during the session
   - Errors or blockers
   - Unresolved problems

5. **Solutions Implemented:**
   - How problems were solved
   - Workarounds used
   - Fixes applied

6. **What Couldn't Be Solved:**
   - Known limitations
   - Deferred tasks
   - Future considerations

7. **Lessons Learned:**
   - Key insights
   - Best practices identified
   - What worked well

8. **Next Steps:**
   - Immediate next actions
   - Follow-up tasks
   - Future sessions planning

9. **Context for Next Session:**
   - Current state of the project
   - Important notes for continuity
   - Handoff information

10. **Documentation Updates:**
    - Which documentation files need updating
    - CHANGELOG entries needed
    - README updates required
    - PRD.md updates needed (if applicable)

11. **Pre-Git Commit Checklist:**
    - [ ] CHANGELOG.md updated with new version entry
    - [ ] README.md updated with new features/changes
    - [ ] PRD.md updated (if feature status changed)
    - [ ] All files reviewed and synchronized
    - [ ] Documentation links verified
    - [ ] Version numbers updated consistently
```

## 📋 USAGE TIPS

### When to Use Each Prompt:

1. **Standard Wrap-Up:** Use for most sessions (balanced detail)
2. **Quick Wrap-Up:** Use for short sessions or simple tasks
3. **Detailed Wrap-Up:** Use for major milestones or complex changes
4. **Gamification-Specific:** Use when working on gamification systems

### Best Practices:

- ✅ **Use at end of session:** Paste the prompt when you're ready to wrap up
- ✅ **Be specific:** Mention any particular areas you want emphasized
- ✅ **Include context:** Mention any important decisions or changes made
- ✅ **Ask for handoff:** Request context for next session if needed

### Example Usage:

```
Session wrap-up: Please create a comprehensive summary of this session including:

1. What We Accomplished
2. Key Decisions Made
3. Files Created/Modified
4. Problems Encountered
5. Solutions Implemented
6. What Couldn't Be Solved
7. Lessons Learned
8. Next Steps
9. Context for Next Session
10. Documentation Updates

Note: We focused heavily on gamification system design and perk structure. 
Please emphasize the Founder Pass pricing decisions and tangible rewards planning.
```
