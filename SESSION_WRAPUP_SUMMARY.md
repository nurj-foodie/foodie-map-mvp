## 2. KEY DECISIONS MADE

### Token Naming:
- **Decision:** Straightforward naming (Food, Photo, Review, Explorer)
- **Rationale:** Clear, trustworthy, matches PRD tone, international-friendly

### Energy vs Explorer Tokens:
- **Decision:** Separate systems (Energy for API costs, Explorer for leveling)
- **Rationale:** Clear purpose, no conflict between progression and utility

### Badge Progression:
- **Decision:** 
  - Beta: Easier progression (5/15/30/60/100) for early engagement
  - Post-Beta: Balanced progression (10/25/50/100/200/500/1000)
  - Multi-tier badges for all badge types
- **Rationale:** Achievable early, challenging long-term, scalable

### XP Migration:
- **Decision:** XP disappears, converts to tokens with beta tester bonus
- **Rationale:** Simplest system, matches post-beta design, no confusion

### Special Perks:
- **Decision:** Option 2 (Balanced) - Recognition + convenience + access
- **Rationale:** Fair, meaningful, Shariah compliant, balanced

### Founder Pass Pricing:
- **Decision:** RM100 (adjusted from RM300 initial plan)
- **Rationale:** More accessible, better value proposition, still exclusive

### Tangible Rewards:
- **Decision:** 
  - Physical merchandise: Pin, Tote Bag, Take-Away Pack (RM30 budget)
  - Events: Simple foodie food taste events
  - Future: Discounts and vouchers (after partnerships)
- **Rationale:** Budget-friendly, no sizing required, scalable

### Beta Tester Discount:
- **Decision:** Achievement-based (5-30% off Founder Pass)
- **Rationale:** Rewards engagement, incentivizes participation
